What is a CPU?

The CPU, or Central Processing Unit, is one of the most important components of a computer. It executes instructions provided by software and performs calculations needed to complete tasks.

🧠 PROCESSING

Processes instructions and performs calculations.

⚡ SPEED

CPU speed is commonly measured in GHz.

🔢 CORES

Modern CPUs can contain multiple processing cores.
