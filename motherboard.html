What is a Motherboard?

The motherboard is the main printed circuit board of a computer. It provides physical and electrical connections between many computer components.

🔗 CONNECTION

Connects different hardware components.

⚡ POWER

Distributes power to connected components.

📡 COMMUNICATION

Allows components to communicate.

Major Components

Component Function
CPU Socket Connects the processor to the motherboard.
RAM Slots Hold RAM modules.
PCIe Slots Connect expansion cards such as GPUs.
M.2 Slot Can connect compatible solid-state storage.
I/O Ports Provide connections for external devices.
